Sobre git

Sobre git discutimos o funcionamento do git, o que é o worckopy, stage, repositório. Os comandos git utilizados são listados abaixo

  • git init | cria um repositório git vazio .git
  • git status | exibe estado do rep.
  • git commit -m "msg" faz um commit
  • git log | lista os commits da branch(ramo)
  • git checkout branch | recupera wk apartir de um branch
